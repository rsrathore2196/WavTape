# WavTape connected Material themes

Settings → Appearance → Choose Theme Preset presents exactly ten choices:
Tideglass, Mosslight, Saffron Haze, Petal Drift, Lilac Loom, Apricot Veil,
Lagoon Mist, Olive Muse, Mulberry Silk, and Night Ink (AMOLED).

Each has one stable ID and coordinated light/dark variants. Appearance's
System, Dark and Light controls change that variant without changing the chosen
identity. Choosing a preset keeps the current appearance mode. Tideglass is
the default, with blue/cyan accents inspired by the WavTape ribbon logo.
Night Ink uses black surfaces in dark mode and a neutral light companion.

Nine HCT recipes provide distinct soft primary, secondary and tertiary accents,
containers and softly tinted surfaces. Each theme/mode resolves once on demand;
no album-art requests, wallpaper source, runtime seed editor or Tonal Themes route
remains. The HCT math is retained solely for the new catalog.

Untouched retired presets migrate to Tideglass (or Night Ink for AMOLED), while
edited/imported custom palettes and legacy backup formats remain readable.
Historical palette data is private migration input and is never shown as choices.
