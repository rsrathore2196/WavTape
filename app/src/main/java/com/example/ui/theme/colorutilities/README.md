Only HCT/CAM16, tonal palettes, and color/math utilities are included. Java
packages/imports are namespaced under `com.example.ui.theme.colorutilities`;
algorithms are otherwise unmodified. They generate the fixed, connected
Material theme catalog. There is no wallpaper/artwork theme feature or editor.
